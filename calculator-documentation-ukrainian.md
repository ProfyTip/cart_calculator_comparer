# Технічна документація калькулятора

## 1. Призначення

`calculator.js` створює інтерфейс калькулятора з двома панелями. Користувач може шукати товари в каталозі, додавати товари до будь-якої панелі, видаляти їх і переглядати підсумки.

Цей код призначений для порівняння різних предметів і використання в каталогах товарів і кошиках покупок. Він може працювати з різними типами об’єктів, включаючи об’єкти, що представляють окреме значення або загальну грошову суму, а також підтримує конвертацію грошових значень у різні валюти. Отримані дані також можуть бути надіслані до зовнішнього API для подальшої обробки або інтеграції з іншими системами.

Код повертає HTML з `Calculator(options)`. Сторінка вставляє цей HTML в елемент з id `calculator`.

## 2. Файли

- `calculator.js`: логіка калькулятора та генерація HTML.
- `test-data.js`: приклад даних каталогу. Визначає `CALCULATORDATA`.
- `calculator-demo.html`: демонстраційна сторінка. Підключає дані, логіку калькулятора та CSS.
- `calculator-demo.css`: стилі демо-сторінки та калькулятора.

## 3. Вхідні дані

Виклик калькулятора здійснюється за допомогою об’єкта параметрів:

```js
Calculator({
  boxAmount: 4,
  CALCULTATORDATA: catalogItems
});
```

`CALCULTATORDATA` має бути масивом. Кожен елемент може містити такі властивості:

| Властивість | Тип | Призначення |
| --- | --- | --- |
| `name` | string | Назва товару. |
| `pic` | string | URL або шлях до зображення. |
| `csign` | string | Позначення валюти або одиниці. |
| `price` | number | Загальна кількість або значення кількості. |
| `value` | number | Цінове значення товару. |

Код приймає різні типи об’єктів і може працювати зі значеннями, що представляють або окреме значення, або загальну грошову суму. Це робить його придатним для порівняння товарів, підрахунку цін і даних каталогу в різних категоріях. Грошові значення можуть бути конвертовані в різні валюти, а оброблені дані можуть бути передані до зовнішнього API для віддаленої обробки або зберігання.

Код використовує порожній масив, якщо значення даних відсутнє або не є масивом.

## 4. Налаштування

| Параметр | За замовчуванням | Опис |
| --- | --- | --- |
| `boxAmount` | `10` | Застарілий параметр. |
| `boxAmountMin` | `4` | Мінімальна кількість комірок у панелі. |
| `boxMainId` | `calcMainBox` | ID головного елемента калькулятора. |
| `boxId1` | `calcBox1` | ID першої панелі. |
| `boxId2` | `calcBox2` | ID другої панелі. |

Якщо `boxAmountMin` має недійсне або непозитивне значення, використовується `4`.

## 5. Модель стану

Калькулятор має два стани панелей: `box1` і `box2`.

Кожна панель зберігає:

- `content`: товари, вибрані користувачем.
- `contentTemp`: товари, показані в поточному пошуку.
- `inputSearch`: поточний текст пошуку.
- `values.total`: сума значень `price` товарів.
- `values.totalValue`: сума значень `value` товарів.
- `amount`: кількість відрендерених комірок у панелі.

## 6. Дії користувача

Інтерфейс використовує делеговані події документа.

- `toggle-search`: відкриває або закриває панель пошуку.
- `search`: фільтрує товари каталогу за назвою.
- `add-item`: додає вибраний товар з каталогу.
- `remove-item`: видаляє товар із панелі.

Дані подій використовують атрибути `data-action`, `data-box` та `data-index`.

## 7. Правила рендерингу

`compileTemplate()` створює весь калькулятор.

`boxTemplate()` створює одну панель і її підсумки.

`compileContent()` створює вибрані товари та порожні комірки.

`compileContentAll()` створює результати пошуку.

Усі значення каталогу, що вставляються в HTML, проходять через `escapeHtml`. Це запобігає інтерпретації тексту каталогу як HTML.

## 8. Форматування чисел

`numberFormat(number, decimals, decimalPoint, thousandsSeparator)`:

1. Перетворює вхідне значення на число.
2. Використовує нуль для не-числового значення.
3. Округлює до потрібної кількості знаків після коми.
4. Додає розділювачі тисяч.
5. Додає потрібний роздільник десяткових знаків.

## 9. Вимоги до браузера

Сторінка вимагає браузер із підтримкою:

- `const` і `let`.
- шаблонних рядків.
- `Element.closest()`.
- `Element.dataset`.
- `Number.isFinite()`.

## 10. Локальне тестування

Відкрийте `calculator-demo.html` у браузері. На сторінці мають відображатися дві панелі калькулятора, а зразковий каталог повинен бути доступний для пошуку.

Для перевірки синтаксису виконайте:

```text
node --check calculator.js
```

Очікуваний результат: відсутній вивід і код завершення `0`.
